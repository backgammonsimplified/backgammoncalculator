# Archived Stage 1 Intended Pair Dependencies

This branch records calculator package source used by the analysis archived in:

archive/stage1-intended-pair-analysis

The preliminary Stage 1 dataset used independent Match A and Match B dice
streams. Pair-outcome functions must not be used as evidence of a common-dice
paired experiment for that dataset.

The functions are preserved for possible reuse in a future campaign that
directly validates genuine common physical-seat dice.
