# Third-party notices

## bglab

GNUID bit-field and conversion concepts were adapted from the MIT-licensed `bglab` project, package version `0.0.0.9000`, source file `R/posid2xgid.R`. The recovered documentation snapshot was built on 2025-01-25. The exact upstream commit was not available in that snapshot.

The local implementation is a material base-R rewrite. It adds a canonical state model, bidirectional encoders, strict validation, stable-player mappings, provenance, normalization, lossiness handling, and regression tests. `bglab` is not a runtime dependency.

See `GNUID_XGID_ATTRIBUTION.md` and `licenses/bglab-MIT.txt` in the installed package.
